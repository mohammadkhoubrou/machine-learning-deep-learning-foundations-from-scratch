# Deep Learning Lab

## Overview
This directory consists of *deep learning* concepts beyond classic *machine learning*, combining theory with implementations of the algorithms from **scratch**. Each section includes mathematical intuition, theoretical explanations, and implementation details to build a solid base of deep learning approaches to solve problems.

## Objectives

In this section we will:
- Comprehensively understand neural networks architecture
- Build deep learning models from scratch
- Learn optimization techniques
- Explore modern training strategies

## Topics Covered

## Prerequisites
This directory assumes that you have a basic familiarity with linear algebra, differentiation, machine learning, loss and cost function, gradient descent, and NumPy.
