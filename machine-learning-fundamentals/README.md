# Machine Learning Fundamentals
This section covers the fundamental concepts underlying machine learning algorithms.

The main purpose is to develop a deeper understanding of how a model:

1. Represents a relationship between inputs and outputs.
2. Makes predictions.
3. Evaluates the predictions.
4. Improves the predictions by updating the parameters.
5. Recognizes the patterns hidden in the data.

The concepts in this section are studied through mathematical explanations, from-scratch implementations, and practical experiments.

## Implementation Philosophy

Whenever appropriate, concepts are first implemented from **scratch** using **basic numerical tools** in order to understand the mathematical operations underlying the algorithms. Established machine learning **libraries** are then used to explore how these concepts are implemented in practical workflows.

The purpose of this approach is to understand not only **how** to use a machine learning algorithm, but also **why and how it works**.
